    Profile

    R

    Default 127.0.0.1 stays on this computer only. Saving a LAN cluster peer automatically binds this desk on your LAN IP so the other host can list your bots.

    LAN cluster

    Work these four steps on http://127.0.0.1:8742/ on this computer. The button for each step is in that step. Do not use Confirm unless you are replacing a token this host already saved.

    Open http://127.0.0.1:8742/ on this machine to edit the mesh. A phone or LAN IP cannot Save token or peers.

    Token: checking…

    1

    Name this computer

    teela-brain, teela-body, or teela-jetson — the name of the machine you are sitting at.

    Next: step 2 — create the token on brain, or paste it on body.

    2

    Shared cluster token

    One password for all three desks. Generate it once on teela-brain, then paste that same string on the others. You can Generate again anytime to reset — then paste the new token on body/jetson.

    Click Generate / reset token. It is saved on this computer immediately. Copy it, then paste on the other hosts. Confirm is not needed on localhost.

    Copied. Next: on teela-body open this tab, click “paste the token”, paste into the box, Save token.

    Paste the token you copied from teela-brain, then click Save token. Leave Confirm blank.

    Pick a button above: create on brain, or paste on body.

    3

    Add the other computer

    On teela-body, add name teela-brain and URL http://10.0.0.10:8742. On teela-brain, add name teela-body and body’s LAN IP, like http://10.0.0.20:8742. IPv4 only — no hostnames.

    Fill name + http://IP:8742, then Save peers. Then step 4.

    4

    Test connection

    Only after steps 2 and 3 are saved on both computers. This tests the last Save, not unsaved boxes.

    
                  
    If Test says no peers, finish step 3. If auth, the two hosts do not have the same token. If offline, the peer URL/IP is wrong or deskd is not running there.
